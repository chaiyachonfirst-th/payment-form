ตั้งค่าผู้ใช้งาน

บทบาทและสิทธิ์ (Phase 2)
  • Foreman — สร้างใบเบิกคืน (ซื้อของ/ค่ารถ)
  • Site Engineer — สร้างงวดงาน + เบิกคืน + ยืนยันเบิกคืน + req PR
  • Procurement — อนุมัติ PR + สร้าง PO + ยืนยันเบิกคืน + จ่าย Pocket Money (น้ำมัน/วัสดุสิ้นเปลือง)
  • Project Manager — สร้าง+เซ็นงวดงานขั้นแรก + จัดการโครงการ + อนุมัติ PO + สร้าง PR
  • Executive — เซ็นงวดงานขั้นสุดท้าย (ต้อง 2 คนต่างกัน) + จ่ายเงินจริง + ลงสลิป
  • PIN 4-6 หลัก — จำเป็นสำหรับทุก role ยกเว้น Foreman
