ตั้งค่าผู้ใช้งาน

บทบาทและสิทธิ์ (Phase 2)
  • Foreman — สร้างใบเบิกคืน (ซื้อของ/ค่ารถ)
  • Site Engineer — สร้างงวดงาน + เบิกคืน + อนุมัติเบิกคืน + req PR
  • Procurement — อนุมัติ PR + สร้าง PO + อนุมัติเบิกคืน + จ่ายเงินจริง (เบิกคืนซื้อของ/ค่ารถ + Pocket Money)
  • Project Manager — สร้าง+เซ็นงวดงานขั้นแรก + จัดการโครงการ + อนุมัติ PO + สร้าง PR + อนุมัติเบิกคืน (ไม่มีอำนาจจ่ายเงิน)
  • Executive — เซ็นงวดงานขั้นสุดท้าย (2 คนต่างกัน) + จ่ายเงินจริง (งวดงาน/PO) + ลงสลิป
  • เบิกคืน 2 ขั้น — Site/PM/Procurement อนุมัติ → Procurement จ่ายเงิน + ลงสลิป
  • PIN 4-6 หลัก — จำเป็นสำหรับทุก role ยกเว้น Foreman
